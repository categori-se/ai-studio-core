# Security

Do not include vulnerability details, real credentials, private endpoints, customer content, or tenant information in a public issue or example.

GitHub's private vulnerability-reporting form is available only when the repository owner enables it. If **Security → Advisories → Report a vulnerability** is present, use that form. If it is absent, open a content-free issue asking the maintainers to provide a private reporting channel; include no security details until that channel has been established.
